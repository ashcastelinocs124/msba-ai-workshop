Before this session, work through [Foundations for ML](mlf-foundations.md): returns, risk, benchmarks, financial and macro data, and the statistics the models use. Page F5 already draws a first line through a cloud of dots; this chapter explains how that line is found.

- **[4.1 Learning From Data](ch04-learning-from-data.md).** Supervised, unsupervised and reinforcement learning, and how a table of months becomes features, a label, vectors, a matrix and parameters.
- **[4.2 Fitting a Line](ch04-fitting-a-line.md).** Linear regression as a numerical prediction, and the loss that turns "how wrong was it" into one number.
- **[4.3 Improving and Judging a Model](ch04-improving-and-judging.md).** Gradient descent as repeated small steps downhill, then overfitting, underfitting and why a model is judged on months it never saw.

All three use the firm's illustrative monthly returns (made up, not market data) and need no API key. One Colab notebook covers the whole chapter.
