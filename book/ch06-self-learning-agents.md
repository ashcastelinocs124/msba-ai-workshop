What the session covers:

- **Introduction to self-learning agents.** How an agent learns from experience and improves over time.
- **The agent learning harness.** An environment where an agent runs a task, receives feedback and improves.
- **Memory and experience.** How an agent stores past experience and applies the lessons to later tasks.
- **Reinforcement and continual learning.** How behaviour adapts through feedback and repeated interaction.
- **Evaluation and measurement.** Measuring learning progress, adaptability and performance across tasks.
